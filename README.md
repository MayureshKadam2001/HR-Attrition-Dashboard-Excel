# HR Attrition Dashboard (Excel)

## 📊 Project Overview
This project analyzes employee attrition using an interactive dashboard built in Microsoft Excel.

## 🔍 Key Features
- KPI metrics (Total Employees, Attrition, Active Employees)
- Gender-wise employee distribution
- Job role-wise attrition analysis
- Travel-based attrition insights
- Work-Life Balance vs Job Satisfaction heatmap
- Interactive slicers

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Slicers
